# DSH 抖音助手

> **这是 [LockyBee/dsh-douyin-agent](https://github.com/LockyBee/dsh-douyin-agent) 的二次开发分支，版本 1.5.0。**
> 上游 1.4.5 的全部功能都在，另外补了下面这几块：评论区读取与自动回复带上护栏、OCR 读屏、本地语音转写接进评论链路、私信策略、全屏保护、@ 我 监测、账单统计。
> 本分支不含上游的独立桌面软件（`desktop/`）和安装脚本，只提供 DSH 插件这一种用法。
> 上游以 MIT 授权，版权声明见 [LICENSE](LICENSE) 与 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

插件与独立软件共用人格、兴趣、观看用量和许可名单。上游固定入口是 1.4.5；**本分支的版本号是 1.5.0，尚未发布到 npm，请直接从源码安装**，见下面的「安装」。

在本机专用 Microsoft Edge 中浏览抖音电脑版，采样真实画面交给模型，按人格和实际观看行为更新兴趣。这是第三方适配，不是 DeepSeek 官方发行版。

## 本分支新增的功能模块

| 文件 | 做什么 |
| --- | --- |
| `comment-reader.mjs` | 读当前作品的评论区，取回每条评论的文本、作者与稳定标识 |
| `comment-reply.mjs` | 真正的「回复某一条评论」通道，带发前护栏、发后复核与额度台账 |
| `comment-guard.mjs` | 评论动作的闸门：同作品不重复、超限就停、状态可疑就退 |
| `comment-voice.mjs` | 生成评论时给模型的语气与口癖（只影响公开评论文本） |
| `ocr-service.mjs` | 本地 OCR 读画面文字，补采样图片之外的标题、字幕类信息 |
| `dm-policy.mjs` | 私信策略：白名单、去重、频率上限，没有许可就不发 |
| `outbound-service.mjs` | 对外发送服务的统一出口，串起护栏、收据与人工核对 |
| `fullscreen-guard.mjs` | 全屏状态保护，避免在播放全屏时误点到别的控件 |
| `mention-watch.mjs` | 翻自己的作品评论区，找「有人 @ 我」的评论并逐一回复 |
| `notify-human.mjs` | 需要人接手时（登录、验证码、发送结果不确定）通知本机 |
| `usage-bill.mjs` | 按官方价目表统计实际请求与 token 花费 |
| `browser-auto-launch.mjs` | 浏览器窗口缺席时自动拉起专用 Edge |

新代码沿用了上游的写法：一个动作能不能做，先看设置与额度，再读真实页面状态确认，最后才动手；任何一步没确认就停下来交给人。

## 上游功能

| 功能 | 用法与范围 |
| --- | --- |
| 自主观看 | 开启“允许自动观看”后，在允许时段和每日额度内挑片、停留、换片或停止；保留手动启动／暂停按钮 |
| 每日额度 | “高级选项”内设置每日观看分钟数和每日模型请求数，均可选不限 |
| 人格与兴趣 | 两版共用人格卡；兴趣依据实际播放进度、观看比例和已确认互动，看到主题不等于喜欢 |
| 好友互动 | 一个总开关管理许可会话的新消息回复及观看中的自主分享，默认开启；须由本人选择许可好友或群聊 |
| 群聊回复 | 仅回复已许可群聊中被 @ 或叫到设定昵称的消息 |
| 自主分享 | 通过官方面板发送当前实际观察作品的卡片，按平台稳定身份绑定收件人，同作品同会话去重 |
| 公开评论 | 独立开关，默认关闭；保留每日及每次观看的尝试上限，同作品不重复评论 |
| 静默观看 | 持续静音，核实窗口归属后尝试最小化；仍使用有窗口 Edge |
| 自检与用量 | 一键诊断、限定修复建议、实际请求与已报告 token 用量、进行中状态 |
| 观看日报 | 从本机观看记录生成 Markdown，不额外调用模型 |
| 可选音频 | 本地 Whisper 转写对白，视频音频还可选择 MiMo 或 MiniMax 云端后端 |

好友互动不设人数、回复请求数或分享次数的业务上限，模型调用仍会消耗额度。默认开启总开关不会自行添加许可会话。旧自动续火花／自动问候入口已移除。

## 安装

需要 Windows、Microsoft Edge、Node.js 22.13+ 和兼容的 DSH（`engines.dsh` 里写的那两代）。

```powershell
git clone https://github.com/Summer77177/dsh-douyin-agent.git
cd dsh-douyin-agent
```

把插件挂进你的 DSH profile：在 profile 的 `package.json` 里把它加进 `dependencies`（指向 clone 下来的目录），再把它加进 `dsh.profile.bundles`，然后完全退出 DSH 重新打开。

```json
{
  "dependencies": {
    "dsh-douyin-browser-local": "file:D:/path/to/dsh-douyin-agent"
  },
  "dsh": {
    "profile": {
      "bundles": ["dsh-douyin-browser-local"]
    }
  }
}
```

插件需要 Windows、Microsoft Edge 和兼容 DSH。已检查 0.2.0-rc.2、0.2.1-rc.2 两代 SDK；完整允许版本以 `package.json` 的 `engines.dsh` 为准，不笼统保证任意 0.2.x 预发布宿主。设置通信适配常用 WebServer、Connection 与宿主 RPC 入口，第三方宿主仍以实际自检和加载结果为准。

装完先只用 `node scripts/verify.mjs` 过一遍语法，再在设置页跑「一键自检」。

## 第一次使用

1. 配置支持图片的主模型。插件从 DSH 目录选择；独立软件在模型设置的密码框填写自己的 Key。
2. 点击“打开抖音”，在专用 Edge 中手动登录或完成验证码。
3. 在“视频观看”选择时段，按需展开“高级选项”设置每日分钟数和请求数，再开启“允许自动观看”。无需先开始新轮次，应用需保持运行。
4. 在“好友互动”读取当前会话，核对稳定身份并勾选许可好友或群聊，按需填写群聊响应昵称。总开关开启且模型、名单就绪后自动准备回复；观看中可自主分享。

普通设置自动保存，文本输入离开输入框后提交，开关和下拉选择修改后提交，以页面回读为准；失败会保留草稿。密钥保留独立保存入口：桌面主模型 Key 走桌面 IPC；音频 Key 在“音频与密钥”密码框填写，离开后通过专用接口保存，不回显，也不会因此开启音频。

## 状态与验证边界

顶部状态栏区分在线、观看中、准备中和需要处理。未确认发送、身份不符或待人工处理的消息会显示原因；不能只凭总开关开启认定服务已就绪。好友回复与观看分开运行，观看时仍检查许可会话的新消息，实际速度受页面读取和模型耗时影响。

遇到问题先运行“自检与用量 → 一键自检”，按报告处理限定修复项。登录、验证码、无效 Key、损坏记录和宿主适配不能靠删除锁、记忆或登录目录解决。发送结果不确定时保留收据，等待人工核对，不自动重发。

本机已核对浏览、采样、暂停、真实模型人格候选和受控卡片流程，稳定身份、最终输入、每日账本及自动保存另有隔离测试。真实群聊、长期连续运行及本轮更新后的新私信自动回复仍需单独实测；MiMo／MiniMax 云端和真实公开评论也不能视为已验收。

后台打开浏览器仍有偶发超时，尚未根治；最小化后的持续播放受网站行为影响。历史某次发送或旧版测试不代表所有账号、宿主和消息类型都通过。记录见 [验证目录](docs/verification/)，保留各自日期和版本。

## 开发与来源

```powershell
node scripts/verify.mjs
```

这个脚本只做一件事：把仓库里所有 `.mjs` / `.js` 过一遍 `node --check`，不联网、不启动浏览器、不碰 `state/`。它不能替代真实联调，也不证明功能可用。

运行状态、Key、登录资料、私信及联系人记录不进入仓库：`state/` 与 `media/.env` 已在 `.gitignore` 里排除，插件默认把运行数据写到 `$DSH_HOME/douyin-browser/` 下。

浏览器控制复用 Playwright；来源见 [功能复用与来源](docs/reuse.md)。原创代码采用 [MIT](LICENSE)，第三方通知见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。模型使用说明见 [skill/SKILL.md](skill/SKILL.md)，历史详细资料见 [docs/details.md](docs/details.md)。
